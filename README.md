# TERRA — Cinematic Real Estate Mockup

A high-end real estate concept inspired by the aesthetic of the supplied reference video: cinematic architecture photography, oversized typography, restrained colors, pill navigation, editorial spacing, subtle grain, and minimal UI.

## Run locally
Open `index.html` in a browser.

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and `/root`.
5. Save. GitHub will provide the live URL.

## Customize for a real client
- Replace the TERRA name/logo.
- Replace the Unsplash image URLs with the client's photography.
- Change Louisville/Kentucky copy to the client's market.
- Connect the form to Formspree, HubSpot, a CRM, or the client's preferred lead system.
- Add IDX/listing integration when the client has an MLS/IDX provider.
