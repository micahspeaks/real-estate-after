# Terrace & Co. — Real Estate Website Mockup

A polished, responsive real-estate website demo built with plain HTML, CSS, and JavaScript so it can be hosted directly on GitHub Pages.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling, layout, animation, and modal styles
- `script.js` — mobile menu, property filtering, property modal, and demo contact form

## Run locally
Open `index.html` in a browser.

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will give you a live URL.

## Customize for a real client
Search the files for:
- `Terrace & Co.` — replace with the agent/team name.
- `Louisville` — replace with the market.
- Unsplash image URLs — replace with the client's listing photography.
- Property names/prices — replace with actual listings.
- `Website concept by Micah SEO Solutions` — keep or replace with your agency credit.

The contact form is intentionally front-end only for the mockup. Connect it to Formspree, Netlify Forms, HubSpot, a CRM, or another form endpoint before using it for real leads.
